# v0.3.10

## Highlights

- Added provider thinking capabilities, including thinking-only models, thinking-off support, default levels, and supported strength configuration.
- Added a visible model thinking submenu with localized levels from off/minimal through maximum.
- Improved chat responsiveness with immediate optimistic user messages, queue/follow-up handling, and Steer support for active Pi runs.
- Reworked provider connection testing to send a real `Reply with exactly: hi` smoke request with thinking disabled, with clearer actionable errors.
- Improved provider settings scrolling, localization, and toast layering above dialogs.
- Fixed thinking submenus being clipped by the model selector scroll container.

## Notes

- Provider metadata migrations run automatically when the app starts.
- Release validation includes the production Electron/Vite build and the full test suite.
