# v0.3.11

## Highlights

- Aligned the built-in Browser inspection contract with Agent Browser, using compact accessibility-tree snapshots and short public refs such as `@e1`.
- Reduced Browser tool output by hiding internal UUIDs, selectors, bounds, backend node IDs, and link URLs unless URLs are explicitly requested.
- Added stable tab handles (`t1`, `t2`) and backend-node targeting with role/name fallback recovery when a page changes.
- Preserved safe confirmation boundaries, stale-ref invalidation, and compatibility with legacy Browser element and tab identifiers.
- Added Browser regression coverage for compact refs, URL opt-in, accessibility inspection, stale nodes, duplicate controls, and legacy input formats.

## Notes

- Release validation includes lint, type checking, the full test suite, and the production Electron/Vite build.
- macOS ARM64 and Windows x64 installers are built and uploaded by the tag-triggered GitHub Actions release workflow. macOS Intel assets use the existing separate workflow.
